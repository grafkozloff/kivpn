# kivpn

`kivpn` — VPN-клиент для частного использования на Windows.

Клиент работает с уже подготовленным сервером. Ниже описаны подготовительные действия: как получить бесплатный сервер в Oracle Cloud Always Free, подготовить его и получить конфигурацию для подключения к `kivpn`.

---

## Что нужно получить после подготовки

После выполнения инструкции должно быть:

1. Облачный сервер за пределами РФ.
2. Публичный IPv4-адрес.
3. Открытые порты:
   - `22/tcp` для SSH;
   - `443/tcp` для VPN;
   - при необходимости `443/udp`.
4. Установленный и настроенный VPN-сервер.
5. Конфигурация для импорта в `kivpn`:
   - `vless://...`
   - `ss://...`
   - `trojan://...`
   - `hy2://...`
   - или файл конфигурации.

---

## Рекомендуемая связка

| Компонент | Рекомендуемый вариант |
|---|---|
| Облако | Oracle Cloud Always Free |
| ОС | Ubuntu 22.04 / 24.04 или Debian 12 |
| VPN-протокол | VLESS + Reality |
| Запасной протокол | Shadowsocks-2022 |
| Основной порт | `443/tcp` |
| Дополнительный порт | `443/udp`, если используется QUIC/Hysteria2 |
| Управление сервером | 3x-ui или аналогичная панель |

## 1. Регистрация в Oracle Cloud

1. Открой:

```text
https://cloud.oracle.com
```

2. Создай аккаунт или войди в существующий.
3. Выбери домашний регион.

Требования к региону:

- регион должен быть за пределами РФ;
- желательно выбрать регион, где доступны бесплатные ресурсы `Ampere A1`;
- домашний регион влияет на доступность Always Free ресурсов;
- домашний регион после выбора изменить нельзя.

4. Пройди верификацию аккаунта.

Для проверки аккаунта может потребоваться банковская карта.

---

## 2. Создание сети в Oracle Cloud

1. В консоли OCI открой:
```text
Menu -> Networking -> Virtual cloud networks
```
2. Нажми:
```text
Start VCN Wizard
```
3. Выбери:
```text
Create VCN with Internet Connectivity
```
4. Укажи имя сети, например:
```text
kivpn-vcn
```
5. Заверши создание сети.

Мастер создаст:

- VCN;
- публичную подсеть;
- интернет-шлюз;
- список безопасности.

---

## 3. Открытие портов в Oracle Cloud

1. Открой созданную VCN.
2. Перейди в:
```text
Security Lists
```
3. Открой список безопасности, привязанный к публичной подсети.
4. Добавь входящие правила.

Минимально нужный набор:

| Направление | Протокол | Порт | Источник                | Назначение                               |
| ----------- | -------- | ---- | ----------------------- | ---------------------------------------- |
| Ingress     | TCP      | 22   | Твой IP или `0.0.0.0/0` | SSH                                      |
| Ingress     | TCP      | 443  | `0.0.0.0/0`             | VLESS Reality / Shadowsocks TCP / Trojan |
| Ingress     | UDP      | 443  | `0.0.0.0/0`             | Hysteria2 / QUIC, если используется      |

Если панель управления сервером будет открываться через SSH-туннель, её порт наружу можно не открывать.

---

## 4. Создание сервера

1. В консоли OCI открой: `Menu -> Compute -> Instances`
2. Нажми: `Create Instance`
3. Задай имя: `kivpn-server`
4. Выбери образ: `Canonical Ubuntu 22.04`, или `Canonical Ubuntu 24.04`, или `Debian 12`
5. Нажми: `Change Shape`
6. Включи опцию: `Always Free eligible`
7. Выбери форму инстанса: `VM.Standard.A1.Flex`, если доступна. Если `Ampere A1` недоступна, выбери: `VM.Standard.E2.1.Micro`
8. В разделе сети выбери:
- созданную VCN;
- публичную подсеть;
- выдачу публичного IPv4.
9. Добавь публичный SSH-ключ.
10. Нажми: `Create`
11. Дождись состояния: `RUNNING`
12. Сохрани публичный IP-адрес сервера.

---

## 5. Создание SSH-ключа в Windows

Выполни в PowerShell:
```powershell
ssh-keygen -t ed25519 -f "$HOME\.ssh\kivpn_oracle"
```

Посмотреть публичный ключ:
```powershell
Get-Content "$HOME\.ssh\kivpn_oracle.pub"
```

Скопируй вывод команды и вставь его в Oracle при создании инстанса.

---

## 6. Подключение к серверу

Для Ubuntu:
```powershell
ssh -i "$HOME\.ssh\kivpn_oracle" ubuntu@SERVER_IP
```

Для Debian:
```powershell
ssh -i "$HOME\.ssh\kivpn_oracle" debian@SERVER_IP
```

Замени `SERVER_IP` на публичный IP сервера.

---

## 7. Базовая подготовка сервера

После подключения выполни:
```bash
sudo apt-get update -y
sudo apt-get upgrade -y
sudo apt-get install -y curl ufw
sudo timedatectl set-ntp true
```

Установка Docker:
```bash
curl -fsSL https://get.docker.com | sh
sudo systemctl enable --now docker
```

Настройка файрвола:
```bash
sudo ufw allow OpenSSH
sudo ufw allow 443/tcp
sudo ufw allow 443/udp
sudo ufw enable
```

Если панель управления будет доступна на отдельном порту и ты захочешь открыть её наружу, добавь этот порт отдельно.

Для частного использования удобнее открывать панель через SSH-туннель и не публиковать её порт в интернет.

## 8. Установка панели управления

Можно использовать `3x-ui` или аналогичную панель для `xray` / `sing-box`.

Репозиторий:
```text
https://github.com/mhsanaei/3x-ui
```

Пример установки:
```bash
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
```

После установки сохрани:

- порт панели;
- логин;
- пароль.

---

## 9. Доступ к панели через SSH-туннель

Если панель работает на порту `2053`, открой на своём компьютере отдельный SSH-туннель:
```powershell
ssh -i "$HOME\.ssh\kivpn_oracle" -L 2053:127.0.0.1:2053 ubuntu@SERVER_IP
```

Затем открой в браузере:
```text
http://127.0.0.1:2053
```

Если панель использует другой порт, замени `2053` на фактический порт.

---

## 10. Создание VPN-конфигурации

Рекомендуемый основной вариант:
```text
VLESS + Reality
```

В панели создай новое входящее подключение.

Пример параметров:

| Параметр           | Значение                       |
| ------------------ | ------------------------------ |
| Protocol           | `vless`                        |
| Security           | `reality`                      |
| Port               | `443`                          |
| Network            | `tcp`                          |
| uTLS / Fingerprint | `chrome` или `firefox`         |
| SNI / Dest         | Публичный HTTPS-сайт с TLS 1.3 |
| Keys               | Сгенерировать автоматически    |
| Short ID           | Сгенерировать автоматически    |

После сохранения скопируй ссылку вида:
```text
vless://...
```

Эта ссылка импортируется в `kivpn`.

---

## 11. Запасной вариант: Shadowsocks-2022

Если нужен второй профиль, создай подключение:

| Параметр | Значение                                                      |
| -------- | ------------------------------------------------------------- |
| Protocol | `shadowsocks`                                                 |
| Method   | `2022-blake3-aes-256-gcm` или `2022-blake3-chacha20-poly1305` |
| Port     | `443` или другой свободный порт                               |
| Key      | Сгенерировать                                                 |

После сохранения скопируй ссылку вида: `ss://...`

---

## 12. Проверка подготовки

Проверь доступность портов с локального компьютера:
```powershell
Test-NetConnection SERVER_IP -Port 22
Test-NetConnection SERVER_IP -Port 443
```

Проверь слушающие порты на сервере:
```bash
sudo ss -lntu | grep -E ':22|:443'
```

Если порт `443` не отвечает:
1. Проверь входящие правила в `Security List` Oracle.
2. Проверь файрвол сервера:
```bash
sudo ufw status
```
3. Проверь, что VPN-процесс или панель действительно слушает порт.
4. Проверь, что порт не занят другим сервисом.

---

## 13. Использование в kivpn

После подготовки:

1. Запусти `kivpn`.
2. Импортируй полученный конфиг:
    - строкой `vless://...`;
    - строкой `ss://...`;
    - файлом;
    - или другим поддерживаемым способом.
3. Подключись.

---

## 14. Если Oracle Always Free не подходит

Если не удалось получить бесплатный инстанс, можно использовать:

- любой другой VPS вне РФ;
- временный триал облака;
- уже готовый конфиг от другого сервера;
- резервные публичные конфиги.

Требования к серверу остаются теми же:

- публичный IP;
- открытые порты;
- рабочий VPN-протокол;
- возможность получить строку конфигурации.
